# M3 指标可得性结论(订单数 / 在线人数等分钟序列)

> 结论日期:本里程碑交付时。本环境为**离线开发环境(无 playwright、无人工登录)**,
> 回放页在线证据无法获得;依团队既定方案与 M3 契约,本结论走
> **“不可得 → 结论文档 + disabled-by-default 指标开关”** 合规降级路径,
> 不臆测、不伪造粒度、不用汇总值冒充分钟值。

## 1. 目标指标(与契约一致)

| 指标 | 导出列(机制就绪) | 语义(口径需真机复核) |
|------|------------------|----------------------|
| 订单数(该分钟新增) | `order_min` | 该分钟新增订单数 |
| 支付订单数(该分钟新增) | `paid_order_min` | 该分钟新增支付订单数 |
| 在线人数(该分钟) | `online_uv_min` | 该分钟在线人数(在线 UV) |
| 观看人数(该分钟) | `view_uv_min` | 该分钟观看人数/观看 UV |

并表约束(extractor/extra_metrics.py):与 `gmv_min` **同一分钟行严格对齐**;
缺失分钟单元格留空("")并注明;时间轴/粒度不一致一律**拒绝并表**,禁止伪造。

## 2. 探测过程与为什么“不可得”

1. **依赖/凭据前提**:回放页(eos.douyin.com/dp/liveScreen)需要已登录且有权限的
   会话。本交付环境未安装 playwright、且无人工扫码配合,`python main.py login` /
   `probe` / `export --room-id` 均无法在本机完成在线读取(M1/M2 交付说明已声明)。
2. **分层探测路径(机制,待真机执行)**:M1 `probe.py` 与 M2 `extractor/trend.py`
   采用 L0(页面图表数据数组)→ L1(被动捕获响应)只读路径;M3
   `extractor/extra_metrics.probe_online()` 复用同源逻辑,在捕获响应中寻找
   “同一时间轴上的多个等长数值序列(订单/在线/人数类键名)”,仅作**结构识别 +
   键名启发式猜测**,绝不把猜测当结论。
3. **结论**:因无法在无凭据环境访问真实回放页,**本交付环境无法确认**页面是否提供
   上述与成交金额同分钟粒度的序列,也无法确认其字段语义 → 记为**不可得(未验证)**。
   缺失的不是代码能力,而是**在线证据**。

## 3. 已并入 / 不可得清单

- **已并入(真实数据层面):无。** 未取得任何在线证据,不并入任何非真实/推测数据。
- **机制层已就绪**:`order_min / paid_order_min / online_uv_min / view_uv_min`
  四列的对齐并入、缺失留空注明、粒度不符拒绝;用 60 分钟夹具的 `extra_metrics`
  合成段演示了“同分钟行严格对齐并入且导出仍通过 M2 校验”。
- **不可得(未验证,待真机复核)**:上述四指标的真实分钟序列、其页面 tab/接口位置、
  字段口径。
- **禁止项已落实**:未引入与分钟时间轴无关的汇总指标;未收集商品/营销/违规事件
  时间轴;未做登录绕过/签名逆向。

## 4. 可行的替代来源(建议真机阶段评估)

- 巨量百应 **“复盘/数据报表导出”**(账号权限内的网页导出 CSV/Excel)可能提供整场
  订单数、成交金额、在线/观看人数等统计——多为**整场汇总或自定义时段**,若确无分钟
  粒度,只能整场/时段使用,不得并入分钟表冒充分钟值;
- 直播大屏其他 tab 或同页其他只读接口(需登录会话内被动观察,不逆向签名);
- 若上述都拿不到分钟级序列,则订单/人数指标保持“不可得”,交付说明如实记录。

## 5. 指标开关(disabled-by-default)

```yaml
# config.yaml
extra_metrics:
  enabled: false     # 默认关闭:不阻断成交金额导出;与 M2 输出完全一致
  column_ids: []     # 真机验证可得后填入,如 [order_min, online_uv_min]
```

开关关闭时:`python main.py export` 行为与 M2 完全一致(四列表头,可通过 diff 对比 CSV)。

## 6. 真机启用步骤(待在线复核后)

1. `python main.py login`(有头人工扫码);
2. `python main.py probe --room-id <id>` 与 `python main.py export --room-id <id>`,
   人工确认回放页趋势/其他 tab 是否提供订单、在线人数等分钟序列及其字段语义;
3. 确认可得 → 编辑 `config.yaml`:`extra_metrics.enabled: true`、
   `column_ids: [已确认的指标]`;再次 export,核对并表列与成交金额行逐分钟对齐、
   缺失分钟留空并注明、原校验仍通过;
4. 仍不可得 → 维持 `enabled: false`,在本文档第 3/4 节补充记录。
