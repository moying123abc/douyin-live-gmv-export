# 按天导入: sessions / export --date(日期口径,T10)

T10 为命令行增加“按天列出并导出已结束场次”,用户可自行按日期使用,无需介入。
两个子命令复用 T9 摸清的账号级只读接口(已登录会话内同源只读 fetch,不做绕过):

```
GET https://eos.douyin.com/data/life/live/room/paged/
    ?start_time=<当日00:00:00 CST epoch>&end_time=<当日23:59:59 CST epoch>
    &page_size=50&order=2&scene=1
```

## 用法

```powershell
# 列出某天(东八区)该账号已结束场次(只读;默认今天)
python main.py sessions --date 2026-09-04
python main.py sessions --date 09-04             # 省略年份 = 当前年份(等价于上一行)

# 自动解析当天每场 room_id 并各导出一个 CSV(加 --excel 另存 xlsx)
python main.py export --date 2026-09-04 --excel
python main.py export --date 09-04 --excel       # 同上;--date 也支持 9.4 这种写法

# 旧模式不变:
python main.py export --room-id <room_id> --excel
python main.py export --fixture data\samples\sample_ended_session_60min.json
```

实测(2026-09-04,已登录):

```
python main.py sessions --date 2026-09-04
> [sessions] 2026-09-04 已结束场次 1 场:
>   - room_id=7000000000000000001  2026-09-04 09:04:21 ~ 2026-09-04 19:00:28  (596m) ...

python main.py export --date 2026-09-04 --excel
> 校验通过(行数=597,合计=2000.00 元,累计=2000.00)
> 产物: data\outputs\live_20260904_7000000000000000001.csv / .xlsx
```

## 日期口径

- `--date` 接受两种写法(**sessions / stats / export --date / daily 一致**):
  - 完整日期 `YYYY-MM-DD`,如 `2026-09-04`;
  - **省略年份的 `MM-DD`**,如 `09-04`、`9.4` —— 省略的年份取**当前年份**(东八区"今天"所在年);
    跨年边界同样按"今天所在年"算(1 月里写 `12-31` 得到的是今年的 12-31,不回退到去年);
  - 两种写法都可用 `-` 或 `.` 分割,月/日允许 1~2 位并自动补零(`2026.9.4` = `2026-09-04`);
- 写法非法(`09/04`、两位年份 `26-09-01`)或**日期不存在**(`2026-13-99`、非闰年的 `02-29`)
  → 打印原因并以退出码 2 结束:不猜测、不臆造日期;
- `--date`(两种写法都一样)按**东八区本地日**解释:窗口 = 当日 00:00:00 ~ 23:59:59(epoch);
- 过滤 `status=4`(已结束);每行解析 room_id/live_id/start_time/end_time 并派生
  start_cst/end_cst/时长(分钟);按开播时间排序;严格按 start_time 落在当日(防御脏数据);
- 输出文件名:`live_<YYYYMMDD>_<room_id>.csv` / `.xlsx`,目录默认
  `config.export.out_dir`(data/outputs);
- 每场沿用与 `--room-id` 完全相同的口径与三条内置校验(时间轴连续/行数/求和≈累计,
  累计缺失 SKIP);校验失败当场拒绝输出(退出码 3)并给明细。

## 无登录/不可达

无登录凭据或页面不可达时,sessions/export --date 会打印人工引导后优雅退出(退出码 2,
不崩溃、不伪造数据);引导包含 `python main.py login` 与命令示例。
