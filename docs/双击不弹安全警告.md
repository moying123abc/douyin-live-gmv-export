# 双击 `.bat` 为什么会弹「无法验证发布者」,以及怎么彻底消掉

## 现象

在项目目录里双击 `启动助手.bat`(以及任何 `.bat` / `.cmd` / `.vbs` / `.js`),Windows 会弹:

> 打开文件 - 安全警告 —— 无法验证发布者。你确定要运行此软件吗?
> 发行商:未知发布者 / 类型:Windows 批处理文件

必须点「运行」才继续。终端里跑 `启动助手.bat`、或 `python gui.py` 都不会弹。

## 实测结论

**这台机器上的防护软件(卡巴斯基 21.26)会拦截"本项目目录树下的脚本类文件"的双击启动**,
弹的就是这个系统风格的安全警告。同目录下 `.pyw` / `.py` 不在它的拦截类型里。

它**不是**"文件来自 Internet"造成的 —— 这一点很关键,因为网上的解法(解除锁定、低风险文件类型)全都无效。

## 证据(都可复现)

| 检查 | 结果 |
| --- | --- |
| 文件有没有下载标记 `Zone.Identifier`(`Get-Item -Stream *` 与 `cmd dir /r` 两把工具) | **没有** |
| 阳性对照:手工给文件打上 `ZoneId=3` 再双击 | **弹窗** → 说明上面的检测方法本身有效,不是漏检 |
| Windows 自己的区域判定 `IInternetSecurityManager::MapUrlToZone` | 树内 3 个路径 + 树外 + `C:\` 全部 **zone=0(本地计算机)** |
| 同目录下分别双击各类启动文件 | `.bat` / `.cmd` / `.vbs` / `.js` **弹**;`.pyw` / `.py` / `.ps1` **不弹** |
| 弹出警告的那个进程里加载的非系统模块 | `C:\Program Files (x86)\Kaspersky Lab\Kaspersky 21.26\x64\com_antivirus.dll` |
| 把文件放到 `E:\Desktop\`、`C:\Users\...\` 再双击 | 正常执行,不弹 |
| 把 `.bat` 换个类型(如 `.pyw`)放在同一目录双击 | 正常执行,不弹 |

试过但**无效**的做法(别再折腾了):

- 右键 → 属性 → 解除锁定:文件没有下载标记,压根没有"解除锁定"这一项;
- `HKCU\Software\Microsoft\Windows\CurrentVersion\Policies\Associations\LowRiskFileTypes` 里加 `.bat;.cmd;.lnk`:实测仍然弹窗;
- 桌面快捷方式:有效,但只是绕开,且用户希望"在项目里双击就行"。

## 现在的做法

项目里提供了 **`启动助手.pyw`** —— 双击它就能开图形界面:

- 不弹安全警告、不闪控制台窗口(比 `.bat` 体验还好);
- 内部逻辑与 `启动助手.bat` 完全一致:找一个 **Python 3.9+ 的 `pythonw.exe`**
  (依次尝试:当前解释器 → 项目 `venv` → `%LOCALAPPDATA%\Programs\Python\Python3xx` → PATH),
  再让它跑 `gui.py`;一个都不满足时用消息框告诉你原因,不会静默失败;
- `启动助手.bat` **保留**,终端里照样能用(终端启动不经过系统这一层检查)。

## 如果你还想让 `.bat` 也能直接双击(需要你手动做)

1. **先确认是谁拦的**:托盘里的卡巴斯基 → 暂停保护(例如暂停 15 分钟)→ 双击 `启动助手.bat`。
   - 不再弹 → 就是卡巴斯基,继续第 2 步;
   - 还弹 → 再用同样办法暂停火绒(HipsTray)试一次,判断是不是火绒的「自定义规则 / 程序执行控制」。
2. **卡巴斯基加排除项**:设置 → 安全设置 → 威胁和排除项 → 管理排除项 → 添加 →
   「选择对象」选文件夹 `E:\Desktop\新建文件夹 (3)\douyin-live-gmv-export`(和 `...\live-ops-tools`)→
   保护组件勾"全部" → 保存。
   若仍然弹:在同一设置里把 `cmd.exe` / `pythonw.exe` 加入**受信任应用程序**;
   或打开卡巴斯基 →「报告」,按时间找到那条拦截记录,里面会写明是哪个组件拦的,再针对那个组件加排除。
3. **火绒的话**:防护中心 → 自定义规则 / 程序执行控制 → 给上面两个目录加信任,或临时关掉对应防护验证一次。
4. **不要**再去动 Windows 侧:区域查询是 zone=0、文件没有下载标记,低风险文件类型名单实测无效。

## 附:一句话给以后的自己

> 遇到「无法验证发布者」先看三件事:① 有没有 `Zone.Identifier`(下载标记);② `MapUrlToZone` 返回几;
> ③ 换成同类不同扩展名(`.pyw`)是否还弹。第①、②条都否定、只有某类扩展名弹,就是机器上装了带注入的防护软件,
> 去它那里加排除项,而不是改 Windows。
