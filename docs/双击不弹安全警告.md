# 双击 `.bat` 弹「无法验证发布者」的真因与处理

## 现象

在项目目录里双击 `启动助手.bat`(以及任何 `.cmd` / `.vbs` / `.js` / `.lnk`)会弹:

> 打开文件 - 安全警告 —— 无法验证发布者。你确定要运行此软件吗?
> 发行商:未知发布者 / 类型:Windows 批处理文件

必须点「运行」才继续;而同样内容的 `.pyw` / `.py` 双击不会弹。终端里跑 `启动助手.bat` 也不会弹。

## 真因:目录带的**低完整性标签(Low IL)**

项目所在的 `E:\Desktop\新建文件夹 (3)` 整棵树有低完整性标签,里面的文件都继承它:

```text
icacls "E:\Desktop\新建文件夹 (3)"
   ... Mandatory Label\Low Mandatory Level:(OI)(CI)(NW)
icacls "...\启动助手.bat"
   ... Mandatory Label\Low Mandatory Level:(I)(NW)
```

Windows 从**低完整性位置**启动"脚本类"文件时会要求确认(这类文件会被当成不可信内容);
`.pyw` / `.py` 不在这一类里,所以不受影响。

这份标签是**沙箱类工具准备这个工作区时留下的**,佐证:同一个目录的 ACL 里还有该沙箱的
capability SID(`S-1-4-...`)、`Everyone:(CI)(DENY)(DC)`,以及工作区根目录下的
`_prescrub_baseline\`(项目文件快照)。也就是说:**这台机器上给工作区套沙箱的那一层,顺带让
Explorer 拒绝直接运行里面的 .bat**。

### 隔离实验(同一个文件、同一个目录、同样的 ACL,只改标签)

| 标签 | 双击结果 |
| --- | --- |
| Medium(默认) | 弹窗=0,正常执行 |
| 改成 Low | **弹窗=1,拒绝执行** |
| 改回 Medium | 弹窗=0,正常执行 |

命令:`icacls <文件> /setintegritylevel Low` / `... Medium`。

### 被排除掉的其他解释(都实测过)

| 猜测 | 为什么不成立 |
| --- | --- |
| 文件"来自 Internet"(下载标记) | `Get-Item -Stream *` 与 `cmd dir /r` 都查不到 `Zone.Identifier`;阳性对照(手工打上 `ZoneId=3`)才会弹 → 检测方法有效 |
| 文件落在 Internet 安全区 | `IInternetSecurityManager::MapUrlToZone` 对树内/树外/C 盘路径全部返回 **zone=0(本地计算机)**;阳性对照(打上 ZoneId=3/4)分别返回 3/4 → 查询可信 |
| 杀毒软件(卡巴/火绒)拦截 | 两个都暂停后**仍然弹窗**;进程里那支 `com_antivirus.dll` 是卡巴常规注入,不是元凶 |
| 低风险文件类型名单 | 往 `HKCU\...\Policies\Associations\LowRiskFileTypes` 加 `.bat;.cmd;.lnk` 实测无效 |
| 桌面快捷方式 | 有效,但只是绕开,且用户希望"在项目里双击就行" |

## 现在的状态

- `启动助手.bat`:**已把完整性标签抬到 Medium**(`icacls ... /setintegritylevel Medium`),双击实测
  **弹窗=0、界面正常起来**;
- `启动助手.pyw`:同一个启动逻辑(挑 Python 3.9+ 的 `pythonw`),**任何标签下都不会弹**,作为兜底;
- 终端里 `启动助手.bat` 照旧可用。

> 如果哪天双击 `.bat` 又开始弹:多半是沙箱重新给工作区打了 Low 标签(它可能按 `(OI)(CI)` 递归下发)。
> 重新执行一次即可(需要对该文件有写权限;非管理员通常也可以,因为你是文件所有者):
> ```powershell
> icacls "E:\Desktop\新建文件夹 (3)\douyin-live-gmv-export\启动助手.bat" /setintegritylevel Medium
> icacls "E:\Desktop\新建文件夹 (3)\live-ops-tools\启动助手.bat" /setintegritylevel Medium
> ```
> 想让整个工作区都不再弹(注意:这会让沙箱里的进程失去对工作区的写权限,除非你不再用沙箱跑这个目录):
> `icacls "E:\Desktop\新建文件夹 (3)" /setintegritylevel (OI)(CI)Medium /T`

## 一条经验(以后遇到同样现象)

> 「无法验证发布者」先按顺序查四件事,别急着怪杀毒软件:
> ① 有没有 `Zone.Identifier` 下载标记;`IInternetSecurityManager::MapUrlToZone` 返回几;
> ② `icacls <文件>` 末尾的 `Mandatory Label\...` 是 Low 还是 Medium(低完整性位置会拦脚本类文件);
> ③ 换成同类不同扩展名(`.pyw`)是否还弹 —— 只有"脚本类"弹就说明是这一类限制;
> ④ 最后才怀疑带注入的防护软件。
> 每一步都用**阳性对照**验证检测手段本身有效(手工造一个"应该弹"的样本),否则会把工具的盲区当成结论。
